# Implementing a vector chatbot with Qdrant and Docker Model Runner

In 2026, if you're in tech then it is very common that everyone is aware of a RAG which is Retrieval Augmented Generation or a vector chatbot. And today we are going to build our own victor chatbot in python in the easiest way possible without making things complicated, so that even a 7 year old kid can also make it.

But wait before moving forward with this article, there are a few things in which you need to have a good idea.

## Prerequisites:
1. Python
2. **Docker Desktop** installed on system
3. **~6GB** of free disk space 
4. QdrantDB

## Architecture:
![vector-chatbot-python](https://ik.imagekit.io/isudiptodas/portfolio-article-images/vector-chatbot-python.jpg)

### Context Creation:
1. Initially I will have a document which is in a txt format where I have around 3000 words written about India.
2. Will use langchain's recursive character splitter for fixed sized based chunking.
3. By running a loop we will pass each chunk for vector embedding conversion in docker inside which I am using **Qwen Embedding Model**
4. After embedding creation, saving the vectors along with text chunk in QdrantDB.

### Chatbot Loop:
1. User will ask a question
2. Question will be converted to a vector embedding.
3. That vector embedding will be passed for query matching in Qdrant
4. Qdrant will return matching vectors along with text chunks
5. Will pass those text chunks + Question + System prompt to an LLM **(Qwen 2.5)** running inside docker.
6. LLM will response with a final output text
7. Render that output to the user

## Implementation code:

***`/qdrant.py`***
```python
import os
from dotenv import load_dotenv
from qdrant_client import QdrantClient, models
from qdrant_client.models import Distance, VectorParams
from langchain_text_splitters import RecursiveCharacterTextSplitter
from openai import OpenAI

load_dotenv()

client = QdrantClient(
    url= os.getenv("QDRANT_CLUSTER_ENDPOINT"),
    api_key= os.getenv("QDRANT_API_KEY"),
)

openaiClient = OpenAI(
    base_url="http://localhost:12434/engines/v1",
    api_key="docker-model-runner"
)

splitter = RecursiveCharacterTextSplitter(
    chunk_size=1000,
    chunk_overlap=100,
)

def createCollection(collectionName, dimension):
    try:
        exists = client.collection_exists(collection_name=collectionName)
        if not exists:
            client.create_collection(collection_name=collectionName, vectors_config=VectorParams(size=dimension, distance=Distance.COSINE)),
            print("COLLECTION CREATED")
    except Exception as e:
        print(f"QDRANT COLLECTION CREATE ERROR -> {e}")

def insertChunk(collectionName, text):

    try:
        chunks = splitter.split_text(text)
        allEmbeddings = createEmbeddings(chunks)

        exists = client.collection_exists(collection_name=collectionName)
        if not exists:
            print("Collection doesn't exists, creating new...")
            client.create_collection(collection_name=collectionName, vectors_config=VectorParams(size=1024, distance=Distance.COSINE)),
            print("COLLECTION CREATED")

        points = []

        for i in range(len(chunks)):
            point = models.PointStruct(
                id = i+1,
                vector=allEmbeddings[i],
                payload={
                    "chunk": chunks[i]
                }
            )
            points.append(point)

        client.upsert(collection_name=collectionName, points=points)
        print("DATA INSERTED INTO VECTOR DB")
    except Exception as e:
        print(f"QDRANT INSERT ERROR -> {e}")

def createEmbeddings(textChunks):
    allEmbeddings = []

    try:
        for i in range(0, len(textChunks)):
            response = openaiClient.embeddings.create(
                input=textChunks[i],
                model="qwen3-embedding:0.6b"
            )

            embedding = response.data[0].embedding
            allEmbeddings.append(embedding)

        print("Embeddings generated")
        return allEmbeddings
    except Exception as e:
        print(f"QDRANT EMBEDDING ERROR -> {e}")


def querySearch(collectionName, question):
    try:
        embedding = openaiClient.embeddings.create(
                input=question,
                model="qwen3-embedding:0.6b"
        )
        
        vectors = embedding.data[0].embedding

        queryResults = client.query_points(
            collection_name=collectionName,
            query=vectors
        )

        allChunks = []

        for i in range(len(queryResults.points)):
            chunk = queryResults.points[i].payload.get('chunk')
            allChunks.append(chunk)
            
        
        completion = openaiClient.chat.completions.create(
            model="qwen2.5:1.5B-F16",
            messages=[
                {"role": "system", "content":"You are a AI assistant and you have to answer users query by the context provided. If you didn't find the context enough to answers, humbly answer back as you dont have access or enough context for this question."},
                {"role": "user", "content":f"QUESTION: {question}, CONTEXT: {allChunks}"}
            ]
        )

        print(completion.choices[0].message.content)
    except Exception as e:
        print(f"QUERY ERROR -> {e}")
```

Now in this file I have implemented all the important functions that are required in the project, like creating embeddings, inserting chunks, search query with vectors etc.

***`/createEmbedding.py`***

```python
import os
from dotenv import load_dotenv
from qdrant import insertChunk

load_dotenv()

def readFile():
    try:
        with open('./india.txt', 'r', encoding='utf-8') as file:
            content = file.read()
            return content
    except Exception as e:
        print(f"ERROR READING FILE {e}")


def saveFileEmbeddings():
    try:
        data = readFile()
        insertChunk(os.getenv("QDRANT_COLLECTION_NAME"), data)
    except Exception as e:
        print(f"ERROR SAVING EMBEDDINGS {e}")

saveFileEmbeddings()
```
In this file we are simply doing two things. We have a function to read the context file of **india.txt** from the project root folder and then based on the file we are creating embeddings and storing in vector database for which we are using the insert chunk function, which we have created in the earlier file.

***`/chat.py`***

```python
import os
from dotenv import load_dotenv
from qdrant import querySearch

load_dotenv()

while True:
    choice = input("Ask anything or exit : ")

    if(choice.strip() == "exit"):
        break
    else:
        querySearch("taakdoom-new", choice)
        choice = ""
```

In this final file, we are simply defining the chat functionality where we are running a while loop in which we are asking every time from the user whether the user wants to ask a new question or exit. And based on that we are performing the operations.
